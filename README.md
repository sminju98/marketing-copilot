# AI 마케팅 운영자 (Marketing Copilot)

**블로그·인스타·알림톡·광고·PR·커뮤니티·로컬까지, 온라인 마케팅을 채널별로 자동화하는 Claude Code 플러그인.**

혼자 마케팅하는 사장님, 그리고 **자기 전문 밖 채널까지 커버해야 하는 마케터**를 위한 겁니다 — 퍼포먼스 하다가 콘텐츠·침투·PR도 돌려야 할 때처럼. 설치하고 "설정하자"라고 치면 — 오늘 뭘 올릴지 만들고, 예약·발행하고, 성과를 기록하고, 다음에 뭘 할지 알려줍니다.

## 설치 (1분)

Claude Code 채팅창에 이 한 줄만 붙여넣으세요:

```
github.com/sminju98/marketing-copilot 이 플러그인 설치해줘
```

설치되면 **"마케팅 설정하자"**라고 치세요. 7가지만 물어봅니다 (내 사업·주력 상품·마진·목표·채널·자동화 범위·계정). 3분이면 끝나고, 그다음부터 매일 아침 "오늘 이거 하세요"가 뜹니다.

> Claude Code가 없으면 [claude.ai/code](https://claude.ai/code)에서 먼저 설치하세요.

## 뭘 해주나

### 손님이 검색으로 찾아오게 — SEO · GEO · 로컬 검색
| 이런 게 필요하면 | 이렇게 해줍니다 |
|---|---|
| 네이버에 검색하면 우리가 뜨게 | 검색 상위에 걸릴 블로그 글을 써주고 발행 직전까지 준비 |
| 구글·ChatGPT가 우리를 추천하게 | 홈페이지 글 자동 발행 + AI 답변에 인용되게 |
| 동네 손님이 지도에서 찾게 | 네이버 플레이스·당근 비즈프로필 채우고 소식 올려줌 |

### 사람들이 우리를 알게 — 콘텐츠·SNS·바이럴·PR
| 이런 게 필요하면 | 이렇게 해줍니다 |
|---|---|
| 인스타 꾸준히 올리고 싶은데 시간이 없다 | 카드뉴스·글 만들어서 예약 시간에 자동으로 올림 |
| 제품 영상 만들고 싶은데 촬영을 못 한다 | 화면 스크린샷만 주면 AI 목소리·자막 넣어 영상 완성 |
| 커뮤니티에 우리 얘기 나오면 대응하고 싶다 | 카페·커뮤니티 감시하다 관련 글에 답변 초안 만들어줌 |
| 언론에 나가고 싶다 | 기사감인지 판단하고 보도자료 써서 어디로 보낼지까지 |

### 왔던 손님이 다시 오게 — CRM·리텐션·다이렉트 마케팅
| 이런 게 필요하면 | 이렇게 해줍니다 |
|---|---|
| 재구매 카톡 보내고 싶은데 과태료가 무섭다 | 법에 안 걸리게 알림톡·문자 자동 판정해서 발송 |
| 단골한테 소식 보내고 싶다 | 뉴스레터·알림톡을 손님 유형별로 자동 발송 |
| 문의를 놓치기 싫다 | 채팅 자동응답·이탈 방지 팝업, 문의 내용에서 다음 아이디어까지 |

### 광고비를 안 태우게 — 퍼포먼스 마케팅·CRO
| 이런 게 필요하면 | 이렇게 해줍니다 |
|---|---|
| 광고 돌리고 싶은데 밑질까 무섭다 | 마진 계산해서 밑지는 광고는 아예 안 켜고, 손실나면 자동 중단 |
| 광고 이미지를 계속 만들어야 한다 | 소재를 규격별로 자동 생성·교체 |
| 광고 눌러도 구매를 안 한다 | 손님이 어디서 나가는지 녹화로 찾아서 고쳐줌 |

### 리뷰·후기가 쌓이게 — UGC·평판 관리
| 이런 게 필요하면 | 이렇게 해줍니다 |
|---|---|
| 리뷰를 늘리고 싶다 | 구매 후 리뷰 요청·체험단 섭외, 법에 맞게 대가 표시까지 |
| 나쁜 리뷰에 대응하고 싶다 | 답변 초안 만들어줌 |

### 뭐가 됐는지 알려줌 — 애널리틱스·어트리뷰션·리포팅
| 이런 게 필요하면 | 이렇게 해줍니다 |
|---|---|
| 어느 채널이 돈이 되는지 모른다 | 측정을 깔아주고 어디서 손님이 오는지 추적 |
| 리포트 만들기 귀찮다 | 모든 채널 성과를 구글 시트로 종합, 슬랙·이메일로 자동 발송 |

## 자동으로 지켜주는 3가지

혼자 하다 사고 나는 지점을 먼저 막습니다.

- 💸 **밑지는 광고는 안 켭니다** — 마진을 계산해서 본전도 못 뽑을 광고는 시작 자체를 막고, 켠 뒤에도 손실나면 자동으로 끕니다.
- ⚖️ **법에 걸리는 발송을 막습니다** — 카톡·문자·이메일 광고는 사전동의·표기 규정을 자동으로 검사합니다. 과태료 3천만원짜리 실수를 안 하게.
- 🔒 **계정 날아가는 자동화는 안 합니다** — "네이버 블로그 자동 포스팅" 같은 건 계정이 정지됩니다. 위험한 건 초안까지만 만들고 발행은 직접 하시게 합니다.

## 매일 어떻게 쓰나

1. 아침에 Claude Code 열면 **"오늘 이거 하세요"** 가 떠 있습니다
2. `오늘 뭐 올리지?` · `이 상품 광고 돌릴 가치 있나?` · `이 글 올려도 되는지 봐줘` 처럼 말 걸면 됩니다
3. 만든 글은 검토하고 승인하면 예약·발행됩니다
4. 주간·월간 리포트가 자동으로 정리됩니다

명령어를 외울 필요 없이 **그냥 말로 시키면** 됩니다.

## 자주 묻는 것

**돈 드나요?** 플러그인은 무료입니다. 광고비와 일부 발송 비용(알림톡 건당 6.5원 등)만 실비로 듭니다.

**개발 몰라도 되나요?** 네. 채팅으로 말 걸면 됩니다. 설정도 대화로 합니다.

**전문 마케터가 써도 되나요?** 네. 오히려 전문 분야 밖 채널을 커버할 때 유용합니다 — 퍼포먼스가 전문인데 콘텐츠·침투·PR을 돌려야 하거나, 채널 하나를 깊게 파던 사람이 나머지를 얹을 때. 각 채널의 법·플랫폼 규정과 자동화 한계를 대신 챙겨줍니다.

**뭐부터 해야 하나요?** 설정할 때 채널 2개만 고르세요. 다 켜면 다 어중간해집니다. 자리 잡으면 그때 늘리면 됩니다.

**AI가 쓴 글, 그대로 올려도 되나요?** 검토는 하셔야 합니다. 확인 안 된 숫자는 표시해서 나오니 그것만 채우고 한 번 읽어보세요. 글당 20~30분입니다.
