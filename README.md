# AI 마케팅 운영자 (Marketing Copilot)

> **트렌드와 고객 반응에서 돈 될 기회를 찾아 콘텐츠·바이럴·광고로 실행하고, 성과를 다시 다음 행동으로 바꾸는 AI 마케팅 운영자.**
> 전략서를 쓰는 AI가 아니라, **오늘 내보낼 값어치가 있는 글·댓글·소재 브리프를 만들고, 반응을 기록하고, 다음 행동을 먼저 제안하는** 행동형 플러그인.
> PM Copilot이 '제대로'의 시스템, Sales Copilot이 '가만히 있지 못하게'의 시스템이라면, Marketing Copilot은 **'내보낼 만한 것을 계속 내보내게'** 만드는 시스템이다 — **빨리 돌되, 아무거나 내보내지 않는다.**

## 이게 특별한 이유
- 💰 **돈 계산이 붙은 마케팅.** "글 잘 쓰는 AI"가 아니다. 손익분기 ROAS = 1 ÷ 마진율, 허용 CAC = 객단가(또는 LTV) × 마진율, 최소 테스트 예산 = 허용 CAC × 10~20 — 이 세 줄이 코어에 박혀 있어서 **편집 방향과 예산이 감이 아니라 숫자로 정해진다.** 마진이 없으면 계산 칸을 지어내지 않고 "확인 필요"로 남긴다.
- 🚦 **게시 게이트가 인프라.** 마케팅은 공개 발화라 실수가 박제된다. 클레임 실증·표시의무(뒷광고 방지)·브랜드 톤·플랫폼 정책·퀄리티 바 5항목을 **경고문이 아니라 게시 전 자동 검사**로 통과시킨다. 미달이면 게시가 아니라 보강 큐로 간다.
- 📉 **양치기 금지가 정체성.** 오가닉에서 저품질 대량은 0이 아니라 **마이너스**다(계정 도달률·검색 평가를 깎는다). 그래서 **편수 목표를 두지 않는다.** 속도는 '아이디어→게시→학습' 사이클 길이에서 내고, 변형 양산은 **매체가 승자를 골라주는 광고 소재에만** 허용한다.
- 📊 **측정 없는 게시 금지.** 나가는 링크엔 UTM, 모든 게시물엔 성과 기록 슬롯. 커넥터가 없으면 게시 24시간·7일 후 "반응 얼마나 왔어요?"를 큐에 넣어 **수동으로라도 기록한다.** 기록 없는 활동은 학습이 안 되고, 학습 없는 활동은 반복 노동이다.
- 🧠 **성과는 콘텐츠가 아니라 메시지에 쌓인다.** 콘텐츠는 소모품(반감기 48시간~수 주), 검증된 **메시지는 복리 자산**이다. 모든 성과를 메시지 ID에 귀속시켜서, 먹힌 각도 하나가 다음 달에 다른 포맷으로 다시 굴러가게 만든다.
- 🔌 **커넥터가 없어도 전 스킬이 동작한다.** GA4·광고계정·SNS 인사이트는 대부분의 사용자에게 없다. 없으면 **로컬 최소 마케팅 DB**(`~/.marketing-copilot/library/`)를 자동 생성해 신호·기회·메시지·콘텐츠·성과를 로컬에 쌓는다. 연결돼 있으면 그 위에서 더 정확해질 뿐이다.
- 🏭 **기획은 이 플러그인, 실행 엔진은 ImageFactory.** 무엇을·누구에게·어떤 메시지로·얼마나 테스트할지는 플러그인이 결정하고, 소재 양산·규격 변환·리프레시·광고 집행은 거래처가 맡는다. **브리프는 표준 포맷이라 아무 디자이너·제작사에게도 그대로 발주 가능하다**(아래 [ImageFactory 연계](#-imagefactory-연계--정직하게) 참조).

## 코파일럿 4형제 + 거래처
| 구성 | 역할 | 은유 |
|---|---|---|
| **Business Copilot** | 무엇을 팔고 어디에 돈·사람을 둘지 결정 | 지휘부(CEO Office) |
| **PM Copilot** | 팔 제품을 만들고 개선 | 기획 사수 |
| **Sales Copilot** | 관계를 계약으로 전환 | AI 영업맨 |
| **Marketing Copilot** (이 플러그인) | **시장의 관심과 인바운드 수요 생성** | AI 마케팅 운영자 |
| **ImageFactory** | 소재 생산·규격 변환·리프레시·캠페인 집행(AdOps) | **거래처(vendor)** — 지휘 대상이 아니라 발주처 |

Business의 `growth`가 내려보낸 목표를 이 플러그인이 받아 실행하고, Sales의 `handoff`(8항목 계약서)를 수신함에서 받아 **회신 의무까지 닫는다.** 형제가 설치돼 있지 않으면 계약서를 파일로 저장해 담당자에게 공유한다.

## 전체 마케팅 플로우
```
브랜드·상품·마진·타깃·톤·클레임 원장 상시 갱신        (context)
  ↓
① 감지   트렌드·키워드·밈·VOC·자사 지표 신호 수집       (signals)
         └ 유효기간(속도형은 짧게) + 출처 등급(실측 > 고객발화 > 외부관찰 > 추측)
  ↓
② 판단   돈 되나·지금인가                              (opportunity)
         손익분기 ROAS = 1 ÷ 마진율 · 허용 CAC · 최소 테스트 예산 · 중단조건 · 근거 등급
  ↓
③ 제작   메시지 선택 → 포맷 → 원본 → 재가공 → 제작 브리프
         (idea → instagram·tiktok·blog·comment → repurpose → brief)
  ↓
🚦 게시 게이트                                          (publish-policy)
   ①클레임 실증 ②표시의무 ③브랜드 톤 ④플랫폼 정책 ⑤퀄리티 바 5항목 ⑥승인 모드
         ├─ 통과 → 배포
         └─ 미달 → 게시 대신 **보강 큐** (편수 채우려고 바를 낮추지 않는다)
  ↓
④ 배포   오가닉 = 초안까지 AI, 게시는 사람   (V1 자동 게시 없음)
         광고   = 캠페인 설계 → 집행 연동     (ads · imagefactory)
         소재   = 브리프 발주 → 규격·변형·리프레시
  ↓
⑤ 학습   성과 기록(커넥터 자동 또는 수동 입력)           (analyze)
         → 콘텐츠가 아니라 **메시지**에 귀속 → 검증 메시지 원장 (messages)
  ↓
다음 행동 제안 — 확대 / 재활용 / 수정 / 중단              (today · weekly-review)
  ↓
Business(실제 CAC·시장 반응) · Sales(인바운드 리드) · PM(VOC) 핸드오프  ↺
```

## 설치 & 3분 설정
1. **설치** — 일반 터미널에서:
   ```
   claude plugin marketplace add sminju98/marketing-copilot
   claude plugin install marketing-copilot
   ```
   (Claude Code 세션 안이라면 `/plugin marketplace add sminju98/marketing-copilot` → `/plugin install marketing-copilot`)
2. **설정** — 클로드에게 **"마케팅 운영자 설정 시작하자"** 또는 `setup`. 질문은 7개다: ①자격·역할 ②브랜드·상품·**객단가와 마진율** ③주요 목표 1개 ④운영/희망 채널 ⑤실행 권한과 승인 모드 ⑥데이터 연결 ⑦ImageFactory 계정 여부.
   - **마진율은 최우선 질문이다.** 없으면 손익 계산이 막히고, 그러면 이 플러그인의 차별점이 통째로 죽는다. 모르면 "나중에"도 되지만 기회 제안이 계속 "확인 필요"로 격하된다.
   - 목표는 **하나만** 고르게 한다(우선순위 강제).
3. **웹훅 1줄 셋업(선택)** — 슬랙으로 브리핑을 받고 싶으면:
   ```bash
   python3 "$CLAUDE_PLUGIN_ROOT/scripts/quicksetup.py" --name "이름" --brand "브랜드" \
     --price 50000 --margin 0.3 --goal revenue --private "<나만보기 웹훅>"
   ```
4. **컨텍스트 한 번** — `context`가 브랜드·상품·타깃·채널·톤·**클레임 원장**을 정리해 저장한다. 로컬 PC(바탕화면·문서·다운로드)에 브랜드·마케팅 자료가 있으면 알아서 찾아 반영한다:
   ```bash
   python3 "$CLAUDE_PLUGIN_ROOT/scripts/find_docs.py"
   ```
5. **써보기** — `오늘 뭐 올리지?` · `이 상품 광고 돌릴 가치 있나?` · `이 글 게시해도 되나 검사해줘`
6. **루틴 등록(선택)** — `routine`이 아침·주간·월간 브리핑을 실제로 등록한다.

설정·데이터는 **`~/.marketing-copilot/`** 에 저장되어 업데이트·재설치해도 유지된다(환경변수 `MKT_COPILOT_HOME`으로 재지정 가능). 파일·JSON을 직접 건드릴 필요는 없다.

## 자동 루프 — 시간 특성에 맞춘 주기
마케팅 유형마다 반감기가 다르다. 속도형을 월간에 넣으면 늦고, 축적형을 매일 보고하면 소음이다. 그래서 주기를 3분류로 나눈다.

| 주기 | 대상 | 내용 |
|---|---|---|
| **매일 아침**(속도형) | 소셜·커뮤니티 | 신규 신호 · 오늘 게시할 콘텐츠(**퀄리티 바 통과분만**) · 댓글 가치 있는 글과 초안 · 승인 대기 소재 · 성과 이상징후 · 새 기회 |
| **업무 중**(워처) | 상시 | 커뮤니티 새 글 · 반응 급등 · 광고 이상 소진 · 소재 피로도 · 인바운드 신호→Sales |
| **매주**(정밀형 판정) | 광고·캘린더 | 다음 주 캘린더 · 채널 성과 리뷰 · **광고 중단/유지/확대 판정** · 재활용 대상 · 신규 테스트 제안 · 제작 물량 산출 |
| **매월**(축적형 리뷰) | SEO·브랜드·예산 | 마케팅비 대비 매출 · 채널 수익성 · 콘텐츠 자산 성과 · 소재 승자/패자 · 예산 배분안 · 구주제 업데이트 큐 |

```bash
python3 "$CLAUDE_PLUGIN_ROOT/scripts/schedule_brief.py" --kind morning   # 아침 큐
python3 "$CLAUDE_PLUGIN_ROOT/scripts/schedule_brief.py" --kind weekly    # 주간 판정
python3 "$CLAUDE_PLUGIN_ROOT/scripts/schedule_brief.py" --kind monthly   # 월간 리뷰
```

**무인 실행에서도 게시·발주·광고 집행은 절대 자동으로 나가지 않는다.** 승인 모드와 예산 상한 안쪽일 때만 자동이고, 나머지는 승인 대기 묶음으로 저장된다.

### 선제적으로 먼저 말 거는 훅 4종
- **세션 시작** — 미설정이면 온보딩 유도. 오늘 큐 미생성·**유효기간 임박 기회**·미회신 핸드오프·**소재 피로도 경보**를 먼저 짚는다.
- **프롬프트 감지** — "게시", "광고", "이벤트", "콘텐츠" 같은 키워드에 해당 스킬과 게시 게이트를 한마디로 안내(세션당 1회).
- **저장 감지** — 콘텐츠 초안을 저장하면 게시 게이트 리마인드 + **메시지 ID 귀속 확인.**
- **세션 종료** — 활동 원장을 남기고, **게시 예정물에 성과 기록 슬롯이 없으면 경고한다**("측정 없는 게시 금지").

## 승인 모드 5종
| 모드 | 동작 |
|---|---|
| `auto` | 허용 범위·예산 상한 안에서 자동 실행 |
| `batch` | 하루·캠페인·캘린더 단위로 묶어 승인 |
| `per_item` | 게시·발주·집행 건별 승인 (**기본값**) |
| `draft_only` | 조사·초안까지만 (게시·발주 안 함) |
| `escalate` | 권한을 넘으면 상급자 상신 |

**모드와 무관하게 항상 승인이 필요한 것:** ①ImageFactory 발주(대외 지출 — `auto`여도 기본 `per_item`) ②광고 집행 개시·예산 증액 ③브랜드 포지셔닝·핵심 메시지 변경 ④가격·프로모션 조건 변경. 광고는 **일·월 예산 상한을 config에 하드 설정**하고, **중단조건 없는 캠페인은 생성 자체를 거부**한다.

## ⚖️ 게시정책·법 — 게시 게이트가 하는 일
게시가 있는 모든 스킬은 게시 전 `publish-policy`를 통과한다.

1. **사실·클레임 검사** — `claims.md` 원장에 없는 수치·효능 주장은 차단하고 "확인 필요"로 반려한다. 광고 심의·표시광고법에서 문제가 되는 건 대부분 "실증 못 하는 주장"이다.
2. **표시 의무 검사** — 광고·협찬물의 광고 표기, 후기·추천의 경제적 이해관계 표시, 커뮤니티 발화의 소속 표시.
3. **브랜드 검사** — 금지 표현, 경쟁사 비방, 과장 표현.
4. **플랫폼 정책 검사** — 채널별 금지(자동 게시·중복 도배·해시태그 스팸).
5. **퀄리티 바 검사(오가닉)** — 아래 5항목 미달이면 게시 반려·보강 큐로.
6. **승인 모드 적용.**

### 커뮤니티·바이럴 3모드 — 뒷광고 모드는 존재하지 않는다
| 모드 | 내용 |
|---|---|
| ① **도움만** | 브랜드 무언급, 그 글의 맥락에 실질 도움만 — 가장 안전하고 가장 자주 쓰는 모드 |
| ② **소속 밝힘** | "저는 ○○ 만드는 사람인데" — 정직하게 밝히고 답한다. 장기 신뢰 자산 |
| ③ **게시 안 함** | 도움도 안 되고 소속 밝히기도 어색하면 안 쓴다 |

**소속을 숨기고 제품을 추천하는 모드는 이 플러그인에 없다.** 공정위 추천·보증 심사지침상 경제적 이해관계 미표시(뒷광고)는 표시광고법 위반이고, 걸리면 브랜드가 커뮤니티에서 영구 박제된다. 단기 전환보다 계정 신뢰가 자산이다.
**댓글도 정예다** — 개수 채우기용 템플릿 댓글은 커뮤니티가 귀신같이 알아보고 신고·차단으로 직행한다. 가치 판정을 통과한 것만 큐에 올린다.

### 자동 게시는 V1에 없다
인스타·틱톡 자동 게시는 공식 비즈니스 API로만 가능하고, 네이버 카페류 커뮤니티는 자동화 자체를 약관으로 금지한다. **V1은 초안 생성까지, 게시는 사람이 한다.** 채널별 공식 API 예약 게시는 확장 단계에서 붙인다. 기능 제약이 아니라 **계정 보호**다.

> **이 도구는 법률 자문이 아니다.** 애매하면 보수적으로 판단하고 전문가 확인을 권고한다. 최종 판단·게시·집행은 사람의 몫이다.

## 📉 양치기 금지 — 이 플러그인의 최대 제품 리스크 방어
AI로 콘텐츠를 뽑는 도구의 기본 실패 모드는 **저품질 대량 생산**이다. 여기서는 배포 지면에서 **승자를 고르는 주체가 누구냐**로 갈라서 처리한다.

| | 오가닉 (소셜·블로그·커뮤니티) | 광고 (퍼포먼스) |
|---|---|---|
| 승자를 고르는 주체 | **플랫폼 알고리즘 + 사람** — 계정 단위 품질 신호(초반 이탈·저장·공유·체류)가 다음 게시물의 도달을 결정 | **매체 시스템** — 변형 N종을 넣으면 기계가 예산을 승자에게 몰아줌 |
| 저품질 대량의 결과 | 계정 도달률 하락·검색 사이트 평가 하락 — **0이 아니라 마이너스** | 패자 변형은 노출이 안 되고 끝 — 하방이 막혀 있음 |
| 따라서 | **소수 정예** — 리듬은 지키되 **편수 목표 금지**, 퀄리티 바 미달이면 게시 대신 보강 | **변형 양산 유효** — 카피 10종·배너 20종 A/B는 여기서만 정당 |

### 퀄리티 바 5항목 — 오가닉 게시의 통과 조건
1. **고유성** — 우리만 말할 수 있는 경험·데이터·사례·관점이 최소 1개 있는가 (누구나 쓸 수 있는 일반론·AI 상식 목록글 차단)
2. **훅** — 3초/첫 장/제목에서 멈출 이유가 있는가
3. **플랫폼 네이티브** — 그 채널의 문법으로 만들어졌는가 (블로그 토막을 카드뉴스에 부은 게 아니라)
4. **행동 유발** — 저장·공유·댓글이 나올 이유를 한 줄로 설명할 수 있는가
5. **사실 검증** — 수치·클레임이 `claims.md` 원장 안에 있는가

**편수 목표가 없다.** 큐에는 "오늘 게시 가치가 있는 것"만 담기고, 캘린더 빈칸은 검증된 메시지의 재활용 후보와 보강 큐를 먼저 소진해서 채운다.
**경보 지표:** 게시당 평균 반응(계정 평균 대비)이 3주 연속 하락하면, 더 올리라고 하지 않고 **"빈도를 줄이고 바를 올려라"를 먼저 제안한다.** 성과가 나쁠 때 더 많이 올리라고 말하는 도구가 되면 안 된다.

## 핵심 지표
전략문서 수가 아니라 **행동량과 전환량**을 본다. 단 마케팅은 공개 발화라 **양 지표 단독은 금지 — 항상 타율과 짝으로 본다.**

| 양 지표 | 반드시 함께 보는 타율 지표 |
|---|---|
| 주간 게시 수(채널별) | **게시당 평균 반응**(계정 평균 대비) · 저장·공유율 |
| 댓글 큐 처리 수 | 답글·후속 대화 발생률 (도배가 아니라 대화가 됐는가) |
| 원본→파생 확장 배수 | 파생물 중 계정 평균 이상 성과 비율 |
| 광고 소재 변형 수 | 승자 변형 비율 · CAC · ROAS |
| 기회 제안 수 | 제안→실행 전환율 · 실행 건의 손익분기 달성률 |

**가장 중요한 내부 KPI: 게시물 중 성과가 기록되고 메시지에 귀속된 비율 — 100%에 가깝게.** 기록 없는 활동은 학습이 안 된다.
```bash
python3 "$CLAUDE_PLUGIN_ROOT/scripts/library.py" stats        # 건수·측정 커버리지·검증 메시지·실행중 캠페인
python3 "$CLAUDE_PLUGIN_ROOT/scripts/library.py" unmeasured   # 게시했는데 성과 기록이 없는 콘텐츠
python3 "$CLAUDE_PLUGIN_ROOT/scripts/library.py" expiring     # 유효기간 임박·경과 신호·기회
python3 "$CLAUDE_PLUGIN_ROOT/scripts/library.py" fatigue      # 피로도 임박 소재(리프레시 시점)
python3 "$CLAUDE_PLUGIN_ROOT/scripts/econ.py" breakeven --margin 0.3   # 손익분기 ROAS
python3 "$CLAUDE_PLUGIN_ROOT/scripts/econ.py" cac --aov 50000 --margin 0.3
```

## 🏭 ImageFactory 연계 — 정직하게
**밝히고 시작한다: ImageFactory는 이 플러그인 만든이(송민주)의 사업이다.** 그래서 추천 규칙을 먼저 못박아 둔다.

- 이 플러그인은 **무료 오픈소스**이고, ImageFactory 없이도 26개 스킬 전부가 동작한다.
- **브리프는 표준 포맷이다.** 브랜드/상품/목표/타깃/핵심 메시지/오퍼/CTA/채널/규격/수량/금지 표현/기한/A/B 가설/UTM/예산 상한 — 그대로 **아무 디자이너·제작사·에이전시에게 전달해도 발주가 된다.** IF 전용 포맷이 아니다.
- 추천은 **소재 양산·규격 변환·리프레시·광고 운영이 실제로 사용자 과업에 걸렸을 때만** 꺼낸다. 관련 없으면 언급하지 않고, 매 답변마다 넣지 않는다.
- **AdOps 광고 집행 연동은 광고비 수수료 기반 유료 서비스다**(요율·조건은 확인 시점 기준이며 최신은 IF 사이트에서 확인). 이해관계가 있는 추천이므로, `ads`는 집행을 제안하기 전에 **준비도 체크(전환 이벤트·랜딩·마진·오퍼)를 먼저 통과시킨다.** 준비가 안 된 계정에 광고를 밀면 광고비만 태우고 끝난다 — 그건 사용자에게도 손해고, 만든이에게도 한 달짜리 매출이다.
- **가용성은 런타임에 확인하고 폴백한다.** 사용자 계정에 집행 연동이 열려 있지 않으면 **매체별 세팅 가이드 + 사전신청 안내로 자동 강등**된다.

**역할 경계 — 플러그인이 절대 하지 않는 것:**

| 플러그인이 한다 (무료) | 거래처가 한다 (유료) |
|---|---|
| 조사·신호·기회 발굴·손익 계산 | 소재 대량 생성 |
| 메시지·카피·대본·구조·캘린더 | A/B 카피·이미지 변형 양산 |
| 제작 브리프(발주서) 작성 | 다지면 규격 리사이즈(세이프존·용량·포맷) |
| 성과 판독·다음 행동 제안 | 소재 리프레시(피로도 대응) |
| 캠페인 설계·타깃·예산·중단조건 판정 | 캠페인 세팅·집행·운영 자동화(AdOps) |
| SNS 콘텐츠 구조·카피·대본·캡션 | SNS 소재 자동생성 *(IF가 연구 중 — 미출시)* |
| 신호 수집·해석·기회 판단 | 트렌드·키워드·밈 분석 엔진 *(IF가 개발 중 — 미출시)* |

플러그인은 **광고 소재의 양산·규격·리프레시를 자체 구현하지 않는다.** 방향 탐색용 저충실도 시안 1~2장까지가 경계다. IF가 연구·개발 중인 영역(SNS 소재 자동생성·트렌드 분석 엔진)은 **자리를 비워두고 인터페이스만 맞춰 둔다** — 출시되면 코드 교체가 아니라 소스 스위치로 붙는다. 미출시 기능을 현재형으로 쓰지 않는 것도 같은 원칙이다.

## V1 범위
1. 7문항 온보딩 + 역할별 동작 + 백본 + **게시 게이트**
2. 컨텍스트 구축(로컬 자료 자동 탐색 + 클레임 원장)
3. 트렌드·키워드·밈 신호 감지(유효기간·출처 등급)
4. ★돈 될 기회 선제발굴(손익 공식 + 고정 제안 포맷 + 근거 등급)
5. 오늘의 마케팅 큐
6. 인스타·틱톡·블로그 어댑터 3종 + **퀄리티 바** + 콘텐츠 캘린더
7. 커뮤니티 댓글 큐(3모드, 가치 판정 통과분만 — 게시는 사람)
8. 재활용 확장(메시지 귀속 + 오가닉/광고 양산 경계)
9. 제작 브리프 + ImageFactory 발주 연결(UTM·승인 게이트·피로도 워처·규격 확장 제안)
10. ★광고 캠페인 설계·집행 연동·중단조건 판정·성과 회수(미개방 계정은 세팅 가이드 폴백)
11. 성과 분석(커넥터 자동 + **수동 기록 루프**) + 검증 메시지 원장
12. 4형제 핸드오프(수신·회신) + 매일/주간/월간 루틴 + 훅 4종

### 확장 로드맵
**거래처 제품 출시에 맞춰 소스 스위치로 승격되는 것** — SNS 소재 자동생성 출시 시 `instagram`·`tiktok`이 브리프 발주 대신 직접 호출로 전환 / 트렌드·밈 분석 엔진 출시 시 `signals`의 1순위 소스로 스위치.

**그 외 순서** — SNS 공식 API 예약 게시 → CRM·이메일(발송정책 재사용) → 인플루언서 발굴·검증 → 어필리에이트·추천 프로그램 → PR·보도 → 오프라인·행사(→Sales 명함 연계) → 쇼핑몰 상품 피드 연동 → 개인화 랜딩 → 다국가·다국어 → 대행사 멀티브랜드 → 숏폼 영상.
