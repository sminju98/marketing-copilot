# design — 한 장씩 필요한 실무 이미지 (DSN-01~12)

이미지가 필요한 순간은 두 종류다. **광고 소재를 규격별로 대량 양산**하는 것은 [[imagefactory]]가 전담한다. 이 스킬은 나머지 — **블로그 삽화 한 장, 제품 배경컷, 상세페이지, SNS 간단 이미지** 처럼 한 장씩 필요한 일상 이미지를 맡는다. 둘은 경쟁이 아니라 역할이 다르다.

이제 **최신 AI 이미지 모델(Nano Banana 2·GPT Image 계열)은 한글 텍스트를 이미지 안에 직접 잘 넣는다** — 예전처럼 "AI는 배경만, 글자는 디자인툴"로 우회할 필요가 없다. 짧은 카피·제목은 AI가 바로 박고, 정교한 상세페이지 레이아웃이나 브랜드 템플릿 양산이 필요할 때만 디자인툴(Canva·미리캔버스)을 얹는다.

## 실행 유형: [A] 파이프라인 설계·프롬프트 작성·API 호출·결과 기록은 자동 / [P] 유료 API 과금 발생분(대량 배치)은 승인 후 / [H] claims.md 밖 문구를 이미지에 넣는 것은 사실 검증 후. 유형별 차이는 [[role]].

## 0. 준비
```bash
cat "${MKT_COPILOT_HOME:-$HOME/.marketing-copilot}/context/"{brand,products,tone,claims}.md 2>/dev/null
python3 "$CLAUDE_PLUGIN_ROOT/scripts/library.py" list message --limit 10
```
- 브랜드 자산(로고·색·폰트) 위치를 확인한다 — 브랜드 일관성은 여기서 시작한다.

## 1. 파이프라인 — AI가 한글까지, 필요할 때만 디자인툴 (DSN-01)

```
① 누끼·배경     제품 사진 → 배경 제거·씬 생성        (Photoroom API)
② 생성·편집     삽화·배경·씬 + 짧은 한글 카피까지     (Nano Banana 2 / GPT Image)
③ 조립(선택)    정교한 상세 레이아웃·템플릿 양산      (Canva MCP / 미리캔버스)
```

- **대부분은 ①②에서 끝난다** — 블로그 삽화, SNS 이미지, 제목·짧은 카피 박힌 배너까지 AI가 직접 만든다.
- ③은 **선택**이다: 긴 상세페이지처럼 정확한 다단 레이아웃이 필요하거나, 상품명·가격만 바꿔 수십 장을 찍어내는 **템플릿 양산**이 필요할 때만.
- 긴 문장이 많거나 오탈자가 치명적인 공식 문서는 ②산출을 사람이 한 번 검수한다(claims 밖 문구 금지).

## 2. 생성·편집층 — Nano Banana (DSN-02~03)

**Gemini의 이미지 생성·편집 모델.** 자연어로 만들고, 기존 사진을 편집(배경 교체·요소 추가/삭제·색 변경)한다. **캐릭터·제품 일관성**(같은 제품을 여러 컷에 반복)이 강점이라 시리즈물·마스코트에 좋다.

| 항목 | 값 |
|---|---|
| 모델명 | **Gemini 3.1 Flash Image (Nano Banana 2)** — 신규는 이걸로 |
| ⚠️ 구버전 | Gemini 2.5 Flash Image는 **2026-10-02 은퇴 예정** → 신규는 2로 |
| 연동 | Gemini API(`ai.google.dev`)에 모델명 지정해 직접 호출. 공식 이미지 전용 MCP는 없음 → API 래핑 |
| 가격 | 이미지 출력 100만 토큰당 $30, 1024px 1장 ≈ 1,290토큰 ≈ **$0.039(약 55원)/장.** AI Studio 무료 티어로 테스트 |
| 한글 | **한글 텍스트 이미지 안에 잘 들어간다.** 짧은 카피·제목은 바로 박는다. 긴 문단만 검수 |

- 연결: `config`에 `design.gemini_api_key` 저장. 없으면 AI Studio 웹에서 수동.
- **정확한 엔드포인트·파라미터는 Gemini API 공식 문서 기준으로 채운다** — 모델명·버전은 바뀌므로 호출 전 현행 모델 ID를 확인한다([확인 필요]).

**대안 — GPT Image**: OpenAI의 이미지 모델(gpt-image-1.5/2)도 한글 텍스트를 잘 렌더한다. 스택이 이미 구글이면 Nano Banana 2로 통일하고, OpenAI를 쓰면 GPT Image로. 둘 다 한글 카피가 박힌 이미지를 직접 만든다.

**용도**: 블로그 삽화, SNS 이미지(짧은 카피 포함), 제품 씬 연출, 개념 도해. **광고 A/B 세트가 아니다** — 그건 [[imagefactory]].

## 3. 제품컷·누끼층 — Photoroom (DSN-04~05)

**제품 사진 배경 제거 + AI 배경 생성·그림자·업스케일.** 커머스 제품컷의 표준.

| 도구 | 연동 | 가격 | 언제 |
|---|---|---|---|
| **Photoroom** | REST API 2종(배경제거·이미지편집), 배치 지원 | 배경제거 $0.02/장, 편집 $0.10/장 | **1순위** — 스마트스토어·쿠팡 제품컷 |
| remove.bg | REST API | 무료 50/월, 유료 장당 $0.10~ | 순수 누끼만, Photoroom 백업 |
| Draph Art (국산) | 공개 API 약함(수동) | 가입 시 배경제거 무료 | **상업사용·저작권프리 라이선스가 명확** — 안심 필요 시 수동 |
| Flair.ai | API | $8~38/월 | 3D 씬·모델 착용컷 등 프리미엄 히어로컷 |

- 세그멘테이션 정확도가 높아(머리카락·투명 유리) 재작업이 적다.
- **광고 소재로 넘기기 전 원본 제품 사진을 정제하는 전처리**로 쓴다 — 누끼 딴 제품컷을 [[imagefactory]] 발주 소재로.

---

## 4. 조립층(선택) — Canva / 미리캔버스 (DSN-06~07)

AI가 한글은 넣지만, **정교한 다단 레이아웃·템플릿 양산**은 디자인툴이 낫다. 상세페이지나 대량 반복물일 때만 얹는다.

| 도구 | 연동 | 강점 |
|---|---|---|
| **Canva** | **공식 MCP `mcp.canva.com/mcp` (OAuth) + Connect API** — 디자인 생성·템플릿 autofill·PNG/PDF/MP4 export | 이 층에서 **유일하게 자동화됨.** 브랜드 템플릿 autofill로 상품명·가격만 바꿔 상세·썸네일 반자동 양산 |
| 미리캔버스 | 공개 API 없음(수동) | 한글 폰트·국내 규격(스마트스토어·쿠팡·카톡·네이버) 네이티브. 감성이 한국형 |
| 망고보드 | 공개 API 없음(수동) | 미리캔버스와 유사, 인포그래픽 |

- **자동 양산이 목적이면 Canva MCP.** 브랜드 킷(색·폰트·로고)을 등록하고 템플릿에 데이터만 채운다.
- **국내 규격·한글 감성이 목적이면 미리캔버스**(수동). 둘은 역할 분담이다.
- 연결: Canva는 `claude.ai → 설정 → 커넥터`에 MCP 추가 후 OAuth.

---

## 5. 표준 워크플로 (DSN-08)

```
원본 제품사진
  → ① Photoroom API: 누끼·배경 생성
  → ② Nano Banana 2 / GPT Image: 삽화·씬·배경 + 한글 카피까지 직접
  → ③ (선택) Canva MCP / 미리캔버스: 긴 상세·템플릿 양산일 때만
  → 완성
  ⇢ 대량 광고 세트가 필요한 순간에만 [[imagefactory]]로 핸드오프
```

**최소 연동 3종**: Nano Banana 2(API) + Photoroom(API) + Canva(MCP). 이 셋이면 블로그삽화·제품배경·상세·SNS를 코드로 커버한다. 나머지(Ideogram·GPT Image·Midjourney 등)는 특수 상황 대안이라 상시 연동 불필요.

## 7. 브랜드 일관성·품질 (DSN-10~11)

- **브랜드 자산 등록**: 색(HEX)·폰트·로고 여백을 `context`에 두고, Canva 브랜드 킷·Nano Banana 프롬프트에 반영한다. 등록 안 하면 매번 룩이 달라진다.
- **긴 한글 문장 검수**: 짧은 카피는 AI가 정확히 넣지만, 문단이 길면 오탈자·줄바꿈을 한 번 본다. 공식·판매 문구일수록.
- **claims.md 밖 문구를 이미지에 박지 않는다** — 이미지 안 텍스트도 표시광고 대상이다.
- **라이선스**: 상업적 사용 가능·저작권 명확한 것만 광고·판매물에 쓴다. CapCut 내장 템플릿·음원, 일부 AI 생성물은 상업 조건이 까다로우니 확인한다.
