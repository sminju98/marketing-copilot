# influencer — 팔로워를 사지 말고 검증된 도달을 발주하라 (INF-01~14)

B2C 초기에 인플루언서·체험단이 주력인 이유는 두 가지다. 첫째, **첫 리뷰와 검색 노출을 만든다** — 광고를 태워도 검색했을 때 후기가 없으면 전환이 안 된다. 둘째, **반감기가 길다** — 광고는 끄는 순간 사라지지만 인플루언서의 리뷰 글·영상은 검색 결과에 남아 몇 달 뒤 구매자도 데려온다.

이 지면의 함정은 두 개다. 하나는 **팔로워 수를 도달로 착각하는 것** — 팔로워를 돈 주고 산 계정에 발주하면 도달이 0이다. 다른 하나는 **단가가 "부르는 게 값"이라는 것** — 기준 없이 협상 테이블에 앉으면 진다. 판별은 데이터로, 단가 상한은 허용 CAC로 잡는다. 둘 다 이 스킬이 자동으로 한다.

## 실행 유형: [A] 소싱·진짜/가짜 판별·단가 상한 계산·브리프 작성·성과 회수는 질문 없이 실행 / [P] 발주·대금 지급은 `approval_mode`에 따라 승인 — 대외 지출이다 / [H] 인플루언서 본문에 개입하지 않는다(가이드라인만 준다). 유형별 차이는 [[role]].

## 0. 준비
```bash
cat "${MKT_COPILOT_HOME:-$HOME/.marketing-copilot}/context/"{brand,products,audiences,tone,claims}.md 2>/dev/null
marketing-copilot library list content --limit 20   # channel=influencer 레코드를 골라 본다
```
- 과거 발주 이력을 먼저 본다 — 같은 인플루언서 재발주면 지난 성과가 단가 협상의 근거가 된다.

## 1. ★소싱 — 블링 무료 분석부터, 돈은 나중에 (INF-01~03)

### 소싱 경로 (INF-01)

| 경로 | 무엇 | 비용 |
|---|---|---|
| **블링(vling.net)** | 유튜브 채널 검색·분석 — **"터진 영상" 자동 발굴**, 유튜버 단가 확인 | **로그인 없이 무료.** 캠페인 제안도 수수료 없이 직접 |
| **레뷰(REVU)** | 국내 최대 체험단 플랫폼 — 블로그·인스타 체험단 모집 대행 | 캠페인 단위 (§2 시장가 참고) |
| 직접 검색 | 우리 카테고리 해시태그·검색어로 활동 계정 탐색 | 무료, 수동 |

**순서는 블링 먼저다.** 공짜로 후보의 성과 데이터를 다 보고 나서 제안한다. 대행·마켓 수수료는 이 과정을 대신해 주는 값인데, 이 스킬이 그 과정을 자동으로 하므로 낼 이유가 줄어든다.

### 후보 발굴 — 전부 자동 (INF-02)

1. 상품·타깃(context)에서 카테고리 키워드 도출
2. 블링에서 카테고리 검색 → "터진 영상"(구독자 대비 조회수 급등 영상) 보유 채널 수집
3. 채널별 예상 단가·평균 조회수 확인
4. 아래 판별(INF-03) 통과 채널만 후보 리스트로 — **선별·우선순위는 AI가 판정한다.** 사람에게 원본 목록을 통째로 던지지 않는다

### 진짜/가짜 판별 — 팔로워 대비 반응 (INF-03)

| 신호 | 진짜 | 가짜 의심 |
|---|---|---|
| **참여율** (좋아요+댓글 ÷ 팔로워) | 규모 대비 일정 수준 유지 | 팔로워는 많은데 반응이 바닥 |
| **댓글 품질** | 내용 있는 문장, 상품 질문 | 이모지 도배·무관한 외국어 |
| 팔로워 증가 곡선 | 완만한 우상향 | 특정일 수직 급등 |
| 조회수 분포 | 영상마다 자연스러운 편차 | 전부 균일하거나 광고 영상만 급락 |

두 개 이상 걸리면 후보에서 뺀다. **이 판별도 AI가 한다** — 사람이 계정을 하나하나 열어볼 필요 없다.

## 2. 시장가 — 기준 없이 협상하지 않는다 (INF-04~05)

### 검증된 시장가 (INF-04)

| 항목 | 값 | 주의 |
|---|---|---|
| 체험단 캠페인 평균 | **[확인 필요]** | 최저 20만~최고 100만원. 견적 취합치라 편차 큼 — 우리 카테고리 실제 견적은 `[확인 필요]` |
| 블로그 리뷰 1건 환산 | **15,000~25,000원** | |
| 인스타·유튜브 개별 인플루언서 단가 | `[확인 필요]` | 채널 규모·카테고리별 편차 — **블링에서 채널별로 확인** |

**여기 없는 수치는 지어내지 않는다.** 개별 견적을 받으면 위 시장가와 대조해 비싼지 싼지만 판정한다.

### 시장가는 참고, 상한은 우리 손익이 정한다 (INF-05)

시장가보다 싸도 허용 CAC를 넘으면 비싼 것이고, 시장가보다 비싸도 허용 CAC 안이면 살 수 있다. 다음 절.

## 3. ★발주 판정 — 지불 상한 = 예상 전환 × 허용 CAC (INF-06~07)

### 계산 (INF-06)

```bash
marketing-copilot econ cac --aov 50000 --margin 0.3   # 허용 CAC
```

```
예상 도달  = 블링의 채널 평균 조회수 (팔로워 수 아님)
예상 전환  = 예상 도달 × 클릭률 가정 × 구매전환율 가정   ← 가정은 보수적으로, 실측 전 '가정'임을 명시
지불 상한  = 예상 전환 × 허용 CAC
```

견적이 지불 상한 이하면 발주 제안, 초과면 **협상 목표가를 붙인 반려안**을 만든다. 첫 발주는 가정이 검증 안 된 상태이므로 소액(1~2건)으로 가정부터 검증한다.

### 승인 — 사람이 남는 자리 (INF-07)

**발주·대금 지급은 [P]다.** 돈이 나가는 확대이므로 `approval_mode`에 따라 승인을 받는다. 승인 요청에는 후보·견적·지불 상한·근거(블링 데이터)를 한 장으로 붙인다. 그 외 소싱부터 협상안 작성까지는 전부 [A]다.

## 4. 브리프와 계약 (INF-08~10)

### 브리프 (INF-08)

발주서는 [[brief]] 표준 포맷을 쓴다. 인플루언서 발주에는 다음을 추가한다.

| 항목 | 내용 |
|---|---|
| 필수 포함 사실 | claims.md 원장 안의 주장만 — **원장 밖 효능·수치를 인플루언서 입으로도 말하게 하지 않는다** |
| 금지 표현 | [[publish-policy]] 클레임 게이트와 동일 기준 |
| 메시지 ID | 이 발주가 검증하려는 메시지([[messages]]) |
| 추적 장치 | 전용 UTM 링크 + 전용 할인코드 (인플루언서별로 다르게) |

### 계약 필수 4종 (INF-09)

이 4개가 빠진 계약은 내보내지 않는다.

| 조항 | 내용 | 빠지면 |
|---|---|---|
| ★대가 표시 문구 | 본문 **첫머리**에 "제공받아 작성" 명시 의무를 계약에 박는다 | 미표시 제재는 인플루언서가 아니라 **광고주**([[review]]와 동일) |
| 2차 활용권 | 콘텐츠를 광고·SNS·상세페이지에 재사용할 권리 | 잘 나온 소재를 못 쓴다 — 소재비 이중 지출 |
| 게시 유지 기간 | 최소 유지 기간을 숫자로 명시 | 검색 자산이 계약 끝나자마자 삭제됨 |
| 수정 횟수 | 횟수를 숫자로 명시 | "한 번만 더"가 무한 반복, 분쟁 |

기간·횟수의 숫자는 협의로 정하되 **반드시 숫자로** 박는다.

### 본문 문구는 지정하지 않는다 (INF-10)

문장 단위로 대본을 주면 그 콘텐츠는 리뷰가 아니라 **광고 대본**이 된다 — 시청자가 먼저 알아채고, 표시광고 리스크도 커진다. 주는 것은 가이드라인까지다: 필수 포함 사실 / 금지 표현 / 보여줘야 할 사용 장면. 말하는 방식은 인플루언서의 것이다. 그게 그 채널이 먹히는 이유다.

## 5. 리스크 (INF-11~13)

| 리스크 | 내용 | 방어 |
|---|---|---|
| **표시 미표기** (INF-11) | 공정위 「추천·보증 심사지침」상 대가 받은 콘텐츠에 경제적 이해관계 미표시 = 표시광고법 위반, **제재 대상은 광고주** | 계약 필수 조항(INF-09) + 게시 후 표시 여부 확인 |
| **팔로워 구매 계정** (INF-12) | 도달 0에 돈 지불 | INF-03 판별을 발주 전 필수 통과 |
| **대본화** (INF-13) | 문구 지정 → 광고 티 → 신뢰·법 리스크 동시 상승 | 가이드라인만(INF-10) |

인플루언서 콘텐츠도 우리 광고물이다 — 게시 전 가이드라인과 게시 후 표시 확인 모두 [[publish-policy]] 게이트 기준을 따른다.

## 6. 성과 회수와 자산화 (INF-14)

게시가 끝이 아니라 회수가 끝이다.

```bash
marketing-copilot library add content --json '{"channel":"influencer","status":"published","title":"...","message_id":"MSG-..."}'
```

| 회수 항목 | 어디로 |
|---|---|
| 전용 UTM·할인코드 전환 → 실제 CAC | 지불 상한 가정(INF-06) 갱신 — 다음 협상의 근거 |
| 성과의 귀속 | 인플루언서가 아니라 **메시지**에 — 어떤 각도가 먹혔는지 [[messages]]에 기록 |
| 잘 나온 콘텐츠 | 2차 활용권으로 소재화 — [[imagefactory]] 규격 확장, [[repurpose]] 전개 |
| 댓글의 고객 발화 | [[signals]]로 — 다음 훅의 재료 |

편수 목표를 세우지 않는다. "이번 달 인플루언서 10명" 같은 목표는 양치기다 — 목표는 검증된 메시지와 회수된 실제 CAC다.
