# promo — 마감이 있는 캠페인 (§2-1 #10 이벤트형 · OPP·CON·IF·ADS 연계)

프로모션과 런칭은 다른 마케팅과 시간 축이 다르다. **마감이 있고, 되돌릴 수 없고, 준비가 안 되면 마감일에 그대로 드러난다.** 그래서 이 스킬은 콘텐츠 스킬이 아니라 **역산 스킬**이다: D-day에서 거꾸로 세어 무엇을 언제까지 끝내야 하는지 못 박고, 오퍼가 마진을 얼마나 갉는지 먼저 계산하고, 채널을 한 방향으로 모은다. 단기간에 소재가 몰리는 유일한 구간이라 **제작 물량 피크**가 여기서 난다.

## 실행 유형: [A] 오퍼 계산·캘린더 역산·채널 전개·물량 산출은 자동 / [P] 게시·발주·광고 집행은 승인 후 / [E] 가격·할인 조건 변경은 상신 — config `approval_mode`·`me.escalate_rules`("가격·프로모션 조건 변경") 적용. 자세히 [[role]]

## 0. 준비 — 상품·마진·기존 캠페인 로드
```bash
marketing-copilot library list campaign --status running
marketing-copilot library list message --status validated --limit 20
cat "${MKT_COPILOT_HOME:-$HOME/.marketing-copilot}/context/products.md" 2>/dev/null || echo "(상품 컨텍스트 없음 — [[context]] 먼저)"
```
- **마감일이 없으면 프로모션이 아니다.** 종료일이 안 정해졌으면 그것부터 정한다 — 상시 할인은 프로모션이 아니라 가격 인하이고, 할인 내성만 남긴다.
- 검증된 메시지가 있으면 그것을 축으로 쓴다([[messages]]). 런칭에서 메시지를 새로 발명하면 마감 전에 검증할 시간이 없다.

## 1. 유형 판정 — 넷 중 하나 (설계가 갈린다)
| 유형 | 핵심 질문 | 주의 |
|---|---|---|
| **신제품 런칭** | 왜 이게 필요한가(문제)부터 세워졌는가 | 기능 나열로 시작하면 안 팔린다. 예열(D-14~7) 구간이 필수 |
| **시즌·기간 프로모션** | 시즌과 우리 상품의 연결이 필연적인가 | 억지 시즌 연결은 신뢰만 깎는다 |
| **재고·마감 소진** | 마진을 얼마까지 내줄 수 있는가 | 2절 마진 잠식 계산이 특히 중요 |
| **이벤트·참여형** | 참여의 대가가 무엇이고 리스트가 남는가 | 경품만 남고 고객이 안 남는 이벤트 금지 |

## 2. 오퍼 설계 — 할인율이 아니라 '지금 사야 할 이유' (OPP-14 연계)
- 오퍼 후보는 할인만이 아니다: **번들·수량 한정·기간 한정·사은품·무료 체험·보증/환불 조건·선착순 혜택·업그레이드.** 할인은 가장 쉽고 가장 비싼 수단이다 — 먼저 나머지를 검토한다.
- **마진 잠식 계산은 필수다.** 할인 후 마진율로 손익분기를 다시 계산한다:
```bash
marketing-copilot econ breakeven --margin 0.18   # 할인 후 마진율로 재계산
marketing-copilot econ cac --aov 41000 --margin 0.18
```
- 판정 문장은 숫자로: "20% 할인 시 마진율 30%→18%, 손익분기 ROAS 3.33→5.56, 허용 CAC 15,000→7,380원. **같은 광고비로는 적자 구간**입니다." 마진이 없으면 계산하지 않고 "확인 필요"로 남긴 뒤 되묻는다(§13-7).
- 목표 수량·목표 매출을 정하고 **역산된 필요 트래픽·필요 전환수**를 적는다. 근거 없는 목표는 목표가 아니라 희망이다.

## 3. D-day 역산 캘린더 — 거꾸로 못 박는다
마감일에서 거꾸로 세어 각 구간의 **산출물과 데드라인**을 고정한다. 소재는 항상 가장 앞에서 막힌다.
```
D-21~14  예열: 문제 제기 콘텐츠·티저·사전 알림 신청(리스트 확보) · ★소재 발주 마감(제작 리드타임 확보)
D-14~7   준비: 랜딩·결제·재고·CS 응대 스크립트 확정 · 전환 계측 점검 · 광고 심사 선제출
D-7~3    고지: 정식 예고·오퍼 공개·기존 고객 우선 안내 · 커뮤니티 답변 큐([[comment]])
D-Day    개시: 전 채널 동시 발화 · 광고 집행 개시([[ads]]) · 실시간 이상 감시
D+1~     유지: 중간 성과 판독·소재 교체·재고/CS 이슈 대응
마감 D-2 / D-1 / 마감 당일  마감 임박 고지 3회 (가장 전환이 몰리는 구간 — 반드시 확보)
D+1~3    종료: 종료 공지·성과 회수·회고 (7절)
```
- **D-Day 이전에 소재 발주 마감이 온다.** 제작 리드타임을 캘린더에 반영하지 않은 프로모션이 가장 흔하게 터진다([[imagefactory]]).
- 캘린더 반영은 [[calendar]], 매일 실행 항목은 [[today]] 큐로 자동 편입한다.

## 4. 채널 총동원 매트릭스 — 같은 오퍼, 채널별 문법
| 구간 | 소셜([[instagram]]·[[tiktok]]) | 블로그·검색([[blog]]) | 커뮤니티([[comment]]) | 광고([[ads]]) | 기존 고객 |
|---|---|---|---|---|---|
| 예열 | 문제 제기·티저 | 구매 판단 글(검색 대응) | 도움만 모드 | 인지·리타깃 풀 적립 | 사전 알림 안내 |
| 고지 | 오퍼 공개·카드뉴스 | 랜딩 연결·비교 정보 | 질문 답변 시 소속 밝힘 | 전환 캠페인 개시 | 우선 안내 |
| 마감 임박 | 카운트다운·재고 잔량 | 업데이트 | 과잉 노출 금지 | 예산 집중 | 리마인드 |
- **채널마다 메시지를 새로 만들지 않는다.** 검증된 메시지 하나를 채널 문법으로 옮긴다([[repurpose]]) — 단 오가닉 파생물은 각각 퀄리티 바 5항목을 통과해야 한다(CON-11 · §2-6).
- **커뮤니티는 프로모션 구간에 특히 조심한다.** 마감 임박이라고 도배하면 계정이 죽는다. 3모드 분류(도움만 / 소속 밝힘 / 게시 안 함)를 그대로 적용한다.

## 5. 소재 물량 산출 — 제작 피크 (IF-01~05)
- 구간별로 필요한 소재를 목록화한다: 예열 티저 / 오퍼 공개 카드 / 채널별 규격 / 광고 변형(카피 × 비주얼) / 카운트다운 / 마감 임박 / 종료 공지.
- **변형 양산은 광고 소재에만.** 오가닉은 소수 정예다(§2-6). 총 수량·규격·기한을 묶어 발주서로 만든다([[brief]]) → 발주는 [[imagefactory]](대외 지출이라 기본 per_item 승인).
- 물량을 D-Day 직전에 몰지 않는다 — 예열용은 D-21에, 마감 임박용은 미리 함께 발주해 둔다.

## 6. 게이트 — 프로모션에 특히 걸리는 것들 (§6-J)
[[publish-policy]] 6단계를 그대로 통과하되, 프로모션은 다음이 추가로 걸린다:
1. **가격 표시** — 할인 전 가격 표기, 할인율·조건·적용 대상의 정확성. 실제로 판매한 적 없는 가격을 정가로 쓰지 않는다.
2. **기간·수량 고지** — 종료 시점과 한정 수량을 명확히. **"한정"이라고 쓰고 연장하면 신뢰가 깎인다.**
3. **조건·제외 대상** — 배송비·중복 사용 불가·환불 조건 등 소비자가 알아야 할 조건을 눈에 띄게.
4. **클레임 실증** — "역대 최저가", "업계 유일" 같은 최상급 표현은 `claims.md` 원장 안에 실증 근거가 있을 때만.
5. **운영 준비** — 재고·결제·배송·CS 응대가 준비됐는가. 마케팅이 성공하고 운영이 터지면 리뷰로 박제된다.
- ⚠️ 이 도구는 법률 자문이 아니다. 애매하면 보수적으로, 표시 문구는 전문가 확인 권고.

## 7. 마감·종료 회고 — 다음 프로모션의 재료 (ANA-16~17)
```bash
marketing-copilot library update campaign <CMP-ID> --json '{"status":"done","actual_revenue":0,"actual_cac":0,"verdict":"...","learned":"..."}'
```
- 회수 항목: 목표 대비 실적 / 채널별 기여 / **할인 후 실질 마진** / 신규 vs 기존 고객 비중 / 마감 임박 구간 전환 비율 / 어떤 오퍼·메시지가 이겼는가.
- **성과는 메시지에 귀속한다**(ANA-17) — 이긴 오퍼 각도는 [[messages]] 원장에 올려 다음 프로모션과 상시 광고에서 재사용한다. 실제 CAC·가격 저항은 Business로 회신([[handoff]]).

## 원칙
- **마감 없는 프로모션은 만들지 않는다.** 종료일·조건이 없으면 그건 가격 인하다. 연장은 신뢰 비용을 계산한 뒤에만.
- **마진 잠식 계산 없는 할인 금지.** 할인 후 손익분기를 계산하지 않고 할인율을 정하는 것은 매출을 늘려 적자를 늘리는 일이다(§13-7).
- **환각 금지.** 없는 재고 수량·예상 매출·업계 할인율·"역대 최저가"를 지어내지 않는다. 근거 없으면 "확인 필요".
- **양치기 금지.** 마감 임박이라고 오가닉·커뮤니티를 도배하지 않는다 — 프로모션 한 번에 계정 신뢰를 태우면 다음 프로모션이 없다(§2-6·§13-3).
- **중단 조건**: 재고·운영 준비 미비 / 가격 표시 근거 불충분 / 광고 중단조건 도달 / 마진 잠식이 손익분기를 넘김 → 개시·확대를 멈추고 조정 또는 [E] 상신.
- **데이터 경계·권한**: 원가·마진·미공개 프로모션 일정은 대외 소재·공유본에 넣지 않는다(`context/_policy.md`). **가격·할인 조건 변경은 [E]** — 마케팅이 단독으로 정하지 않는다.
