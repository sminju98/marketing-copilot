# cafe — 대형 카페는 침투하는 곳이 아니라 입점하는 곳이다 (CAF-01~16)

네이버 카페엔 구매 직전 트래픽이 모인다. 사고 싶은 사람이 검색해서 들어와 "이거 써본 분?"을 묻는 곳이라, 여기 노출은 광고 클릭보다 전환에 가깝다. 그리고 이 지면은 이미 상품화돼 있다 — 아프니까사장이다(회원 194만)는 공식 광고상품을 별도로 운영하고, 파우더룸은 브랜드 입점·체험단 상품으로 연 1,700여 브랜드를 받으며 주 3회 체험단을 연다. 지역 맘카페는 유료 '입점업체' 게시판을 두는 곳이 흔하다. 돈 내고 정식으로 들어가는 문이 열려 있다는 뜻이다.

함정은 문을 놔두고 담을 넘는 것이다. 대부분의 대형 카페는 일반 홍보를 전면 금지한다 — 몰래 들어가 회원인 척 추천하면 경제적 이해관계 미표시로 표시광고법 위반이고, 공정위가 위장 댓글에 광고주 제재을 부과한 선례가 침투의 대가를 보여줬다. 책임은 대행사가 아니라 광고주에게 귀속됐다. 반면 공식 경로는 '걸릴 위험'이라는 개념 자체가 없다 — 카페 운영진이 허가한 자리에, 광고임을 표시하고, 구매 직전 트래픽 앞에 합법적으로 서는 것이다.

[[comment]]과는 완전히 다른 트랙이다. comment는 개인 계정으로 도움 답변을 다는 일(소속 표시·건별 승인)이고, 이 스킬은 회사 대 카페의 공식 거래다 — 견적을 받고, 손익을 계산하고, 돈을 내고 들어간다. 사람이 반드시 남는 자리는 돈이 나가는 발주 승인 하나다.

## 실행 유형: [A] 카페 후보 선정·공식 경로 조사·견적 요청 문안·손익 계산·성과 회수·연장/중단 제안은 질문 없이 실행하고 통보 / [P] 발주·입점비 지불·연장 계약은 승인 — 돈이 나가는 확대다(approval_mode 참조) / [H] 브라우저 연결이 없을 때의 카페 게시 버튼(공식 API 없는 지면), `claims.md` 원장 밖 사실 검증. 유형별 차이는 [[role]].

## 0. 준비 — 손익 계산의 재료부터 (CAF-01)
```bash
cat "${MKT_COPILOT_HOME:-$HOME/.marketing-copilot}/context/"{brand,products,audiences,tone,claims}.md 2>/dev/null
marketing-copilot library list content --limit 20
```
- `audiences.md`의 타깃이 어느 카페에 모여 있는지가 출발점이다. 모르면 `skills/comment/communities-kr.md`(분야별 국내 대표 커뮤니티 44곳 — 규모·홍보 규정·공식 진입 경로)를 먼저 편다.
- 마진율·객단가가 컨텍스트에 없으면 5절의 손익 계산이 안 돈다 — [[context]]로 먼저 채운다.

## 1. ★트랙 판정 — 이 카페는 어느 문으로 들어가는가 (CAF-02)

| 상황 | 트랙 | 가는 곳 |
|---|---|---|
| 공식 광고상품·입점 게시판·체험단이 **있다** | 공식 입점 — 이 스킬 | 아래 2절부터 |
| 공식 경로가 **없고** 도움 답변은 허용 | 댓글 트랙 — 개인 계정·소속 표시·건별 승인 | [[comment]] |
| 홍보 전면 금지 + 공식 경로도 없음 | 진입하지 않는다 — 관찰만 | [[signals]] |
| "회원인 척 후기 올려줘" 요청 | 만들지 않는다 — 표시광고법 위반, 어떤 요청에도 | — |

- 두 트랙은 병행할 수 있다: 입점 전 [[comment]]로 그 카페의 질문 패턴·말투를 학습하고, 입점 후에도 도움 답변은 계속 단다. 단 같은 글에서 두 역할을 섞지 않는다.

## 2. 카페 후보 선정 — 어디에 우리 고객이 있는가 (CAF-03~04)

`communities-kr.md` 44곳에서 우리 카테고리와 맞는 카페를 자동 선별하고, 아래 3개 기준으로 우선순위를 매긴다. 선별·순위는 AI가 한다 — 사용자에게 "어디가 좋을까요"라고 되묻지 않는다.

| 기준 | 보는 것 | 확인 방법 |
|---|---|---|
| ① 활성도 | 일 게시글 수·최신 글 시각 | 카페 메인·게시판 자동 열람 |
| ② 수요 밀도 | 우리 카테고리 질문 빈도("○○ 추천"·"○○ 써본 분") | 카페 내 검색 |
| ③ 공식 경로 존재 | 광고상품 공지·입점 게시판·체험단 모집 | 공지사항·운영원칙 게시판 |

- 회원 수보다 ①②가 먼저다 — 회원 100만이어도 일 게시글이 안 나오면 죽은 카페다.
- 지역 B2C(학원·병원·식당·소매)는 전국구 카페보다 **지역 맘카페**가 우선이다 — 유료 입점업체 게시판 구조가 흔하고, 상권과 회원이 겹친다.

## 3. 공식 경로 조사 — 문은 세 종류다 (CAF-05~07)

후보 카페마다 어떤 문이 있는지 조사한다(공지·운영정책·대표 문의처 자동 열람).

| 유형 | 구조 | 예 | 맞는 상황 |
|---|---|---|---|
| **광고상품형** | 카페·운영사가 배너·게시글 광고 상품을 판다 | 아프니까사장이다(회원 194만) — 공식 광고상품 별도 운영 | 소상공인 대상 상품·노출량 구매 |
| **입점 게시판형** | 월/기수 단위 입점비를 내고 업체 게시판 글 권한 | 지역 맘카페의 유료 '입점업체' 게시판 | 지역 B2C — 꾸준한 반복 노출 |
| **체험단·브랜드관형** | 제품 제공+운영비로 회원 체험단 모집 | 파우더룸 — 연 1,700여 브랜드, 주 3회 체험단 | 후기 자산이 필요한 소비재 |

- 단가·조건은 카페마다 다르고 비공개인 곳이 많다 — **모르는 값은 지어내지 않는다.** "확인 필요"로 두고 다음 단계(견적 요청)에서 확인한다.
- 체험단형으로 가면 운영 설계·대가 표시 상세는 [[review]]가 맡는다.

## 4. 견적 요청 — 문안은 자동으로 만들어 보낸다 (CAF-08)

견적 요청은 돈이 나가지 않는 문의라 자동이다. 카페 대표 메일이 있으면 발송까지 하고 통보, 카페 내 문의 게시판·쪽지만 있으면 브라우저로 채워두고 진행한다(연결 없으면 버튼만 사람).

| 문안 필수 항목 | 이유 |
|---|---|
| 상품 구성·단가·최소 기간 | 손익 계산의 분자 |
| 노출 위치·형태(게시판/배너/고정글) | 유입 추정의 근거 |
| 유사 카테고리 브랜드의 과거 성과 자료 | 예상 유입을 지어내지 않기 위한 실측 근거 |
| 게시물 규정(표시 문구·외부 링크·수정 가능 여부) | UTM과 대가 표시가 가능한지 사전 확인 |

- 외부 링크·UTM이 금지된 지면이면 성과 귀속이 불가능하다 — 그 카페는 우선순위를 내린다(측정 없는 게시 금지).

## 5. ★손익 계산 — 입점비는 CAC로 환산해야 보인다 (CAF-09~11)

```bash
marketing-copilot econ cac --aov 50000 --margin 0.3    # 허용 CAC (재구매 있으면 --ltv)
marketing-copilot econ breakeven --margin 0.3          # 손익분기 ROAS = 1 ÷ 마진율
```

핵심 공식 하나: **필요 전환 수 = 입점비 ÷ 허용 CAC.** 월 입점비를 허용 CAC로 나누면 "이 카페에서 한 달에 몇 명이 사야 본전인가"가 나온다. 이 숫자를 카페의 성과 자료·수요 밀도(2절 ②)에 대본다.

| 판정 | 조건 | 행동 |
|---|---|---|
| 진행 | 필요 전환 수가 성과 자료·수요 밀도 대비 현실적 | 최소 기간(1개월/1기수)으로 발주 상신 |
| 조건부 | 카페가 성과 자료를 못 줌 — 예상 유입 근거 없음 | 최소 단위 테스트만 상신 + 회수 시점 명시. 예상치를 만들어 채우지 않는다 |
| 기각 | 최소 견적으로도 필요 전환 수가 수요 밀도상 비현실적 | 기각 사유 기록 + [[comment]] 트랙 검토 |

- 예상 유입·전환율을 **지어내서 진행 판정을 만들지 않는다.** 근거가 없으면 조건부(최소 테스트)가 상한이다.
- 견적이 여러 개 모이면 필요 전환 수 기준으로 자동 순위를 매겨 한 표로 상신한다.

## 6. 발주 승인 — 사람이 남는 유일한 자리 (CAF-12)

```
📋 카페 입점 발주 상신 — {카페명}
경로: {광고상품 | 입점 게시판 | 체험단} · 기간 {…} · 견적 ₩{…} (견적서 기준)
손익: 허용 CAC ₩{…} → 필요 전환 {n}건/월 · 근거 {카페 성과 자료 | 없음 → 최소 테스트}
중단조건: 기간 종료 시 실제 CAC > 허용 CAC이면 연장하지 않음
승인하면: 발주 → 게시물 제작([[brief]]) → 집행 → 24h/7d/기간말 성과 회수
```
- 승인 없이 결제·계약하지 않는다. 반대로, 승인이 필요한 건 이 단계뿐이다 — 다른 단계를 여기로 끌고 와 사람을 늘리지 않는다.

## 7. 집행 — 공식 경로여도 UTM·대가 표시는 면제가 없다 (CAF-13~14)

- **모든 링크에 UTM**(`utm_source=cafe_{카페슬러그}` 등). 성과는 게시물이 아니라 메시지에 귀속한다([[messages]]).
- **대가 표시**: 입점 게시판 글·체험단 후기·협찬 콘텐츠 전부 본문 첫머리에 경제적 이해관계를 표시한다(표시광고법·추천보증 심사지침). "공식 입점이니 광고인 줄 알겠지"는 면제 사유가 아니고, 체험단 참가자의 미표시 제재도 광고주 몫이다 — 표시 관리 기준은 [[review]]를 따른다.
- **카페 회원에게 쪽지·단체 DM을 보내지 않는다** — 사전 동의 없는 광고성 정보 전송은 정보통신망법 제50조 위반 소지에 카페 규정 위반이다. 입점은 게시 지면을 산 것이지 회원 명단을 산 게 아니다.
- 게시 전 [[publish-policy]] 6게이트를 통과한다. 수치·효능·최상급은 `claims.md` 원장 안의 것만 쓴다.
- 게시는 공식 API가 없는 지면이다 — 승인된 게시물은 브라우저(사용자의 로그인된 크롬)로 게시까지 실행하고, 연결이 없으면 채워두고 버튼만 사람이 누른다.

## 8. 성과 회수 → 연장/중단 판정 (CAF-15~16)

```bash
marketing-copilot library add content --json '{"title":"{카페} 입점 게시물","channel":"cafe","format":"placement","message_id":"MSG-...","status":"published","source_url":"..."}'
marketing-copilot library add performance --json '{"target_kind":"content","target_id":"CON-...","message_id":"MSG-...","input_mode":"manual","metrics":{"views":0,"clicks":0,"inquiries":0,"conversions":0},"note":"입점 {n}주차"}'
```
- 기간 말 실제 CAC = 입점비 ÷ 실제 전환 수. **실제 CAC ≤ 허용 CAC → 연장 상신[P] / 초과 → 연장 안 함이 자동 기본값** — 돈을 안 쓰는 방향은 승인이 필요 없다.
- 입점 글에 달리는 질문·문의 댓글은 [[comment]] 큐로 넘겨 답한다 — 질문이 쌓이는 카페가 연장 1순위다.
- 구매·제휴 신호(견적 문의·도입 검토)는 [[handoff]]로 영업에 넘긴다.
- 반복해서 먹히는 표현은 [[messages]] 원장에 후보로 올린다 — 입점비로 산 것 중 가장 오래 남는 자산이다.
