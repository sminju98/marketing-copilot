# review — 대가를 걸면 표시 의무가 따라온다 (REV-01~15)

B2C 온라인에서 리뷰는 **두 번 일한다.** 첫째로 구매 직전 사람의 마음을 바꾸고(전환율), 둘째로 검색 결과에 우리 얘기를 깔아둔다(노출). 광고비를 태우기 전에 리뷰가 깔려 있어야 같은 광고비가 더 팔린다.

그런데 이 지면의 위험은 플랫폼이 아니라 **공정위**다. 공정위 「추천·보증 등에 관한 표시·광고 심사지침」상 대가를 받은 후기에 경제적 이해관계를 표시하지 않으면 표시광고법 위반이고, **제재 대상은 후기를 쓴 사람이 아니라 광고주**다. 그리고 표시 대상 범위가 넓어져 **경품·포인트·적립금·환급 같은 조건부 대가까지** 포함된다.

## 실행 유형: [A] 리뷰 요청 설계·체험단 기획·부정 리뷰 대응 초안·재활용 소재 추출은 질문 없이 실행 / [P] 체험단 발주와 리뷰 이벤트 집행은 승인 — 대외 지출이다 / [H] 리뷰 본문에 개입하지 않는다. 유형별 차이는 [[role]].

## 1. ★첫 판정 — 대가가 걸렸는가 (REV-01)

무엇을 하든 이 판정이 먼저다.

| | 대가 없음 | **대가 있음** |
|---|---|---|
| 예 | 그냥 남긴 후기, 리뷰 요청 알림톡(보상 없음) | 적립금·쿠폰·제품 제공·체험단·이벤트 응모권 |
| 표시 의무 | 없음 | **필수** |
| 표시 위치 | — | 본문 **첫머리**, 소비자가 쉽게 인식할 수 있게 |
| 미표시 시 | — | 표시광고법 위반 — **광고주가 제재 대상** |

### 표시 대상이 되는 대가 (REV-01a)

넓게 잡는다. 애매하면 표시한다.

```
✓ 제품 무상 제공        ✓ 원고료·현금
✓ 적립금·포인트·쿠폰    ✓ 할인 혜택
✓ 경품 응모권           ✓ 환급 약속
✓ 향후 제공 약속(조건부) ✓ 서비스 무료 이용권
```

**"소액이라 괜찮다"는 기준이 없다.** 금액이 아니라 **경제적 이해관계의 존재**가 기준이다.

### 표시 방법 (REV-01b)

```
✅ "OO사로부터 제품을 제공받아 작성했습니다"   ← 본문 첫머리
✅ "적립금을 지급받고 작성한 후기입니다"

❌ 본문 맨 끝 / 해시태그 사이에 숨기기
❌ 흐린 색·작은 글씨
❌ "체험단" 단어만 던지기 (무슨 대가인지 불명확)
```

## 2. 자사 리뷰 확보 — 돈 안 드는 쪽부터 (REV-02~05)

### 요청 타이밍 (REV-02)

```
배송완료 +3일   ← 써봤고 기억이 선명한 시점
너무 이르면     아직 안 써봐서 형식적 후기
너무 늦으면     잊어버림
```

### 요청 채널 (REV-03)

| 채널 | 도달 | 비고 |
|---|---|---|
| **알림톡** | ★가장 높다 | [[alimtalk]] — 단, 적립금을 걸면 광고성이 된다 |
| 이메일 | 보통 | [[email]] |
| 패키지 동봉 카드 | 의외로 높다 | 오프라인 접점 |

### ⚠️ 여기가 함정이다 (REV-04)

```
"후기 남겨주세요"                  → 정보성. 동의 없이 발송 가능
"후기 남기면 적립금 1,000원"        → 광고성! 동의·(광고)표기·야간금지 전부 적용
                                     + 작성자는 대가 표시 의무 발생
```

**적립금을 거는 순간 두 가지가 동시에 켜진다** — 발송 쪽의 광고성 요건과, 후기 쪽의 표시 의무. 이걸 모르고 운영하는 곳이 많다.

### 좋은 리뷰를 얻는 법 (REV-05)

- **질문을 준다.** "어떠셨나요"보다 "어떤 점이 좋았고 아쉬웠나요"가 구체적인 답을 만든다
- 사진 리뷰에 가중치를 둔다 — 검색 노출과 전환에 둘 다 유리
- **낮은 평점을 지우지 않는다.** 5점만 있는 상품은 오히려 신뢰가 떨어지고, 조작 의심을 부른다

## 3. 체험단 — 사기 전에 계산 (REV-06~09)

### 언제 쓰나 (REV-06)

| 맞다 | 아니다 |
|---|---|
| 신제품 출시로 리뷰가 0개일 때 | 이미 리뷰가 충분할 때 |
| 검색 결과에 우리 얘기가 없을 때 | 제품에 확신이 없을 때 (나쁜 후기가 박제된다) |
| 시각적으로 보여줄 게 있을 때 | B2B·고관여 상품 |

### 비용 감각 (REV-07)

견적 편차가 커서 업계 평균은 무의미하다 — **우리 카테고리 실제 견적 [확인 필요]**(20만~100만원, 인원·제품 단가·조건에 따라 변동), 블로그 리뷰 1건 환산 **15,000~25,000원** 선이다.
> 이 수치는 견적 취합치라 편차가 크다 — **실제 견적을 받아 확인한다.**

econ으로 판단한다.
```bash
python3 "$CLAUDE_PLUGIN_ROOT/scripts/econ.py" --help
```
- 리뷰 1건당 비용 vs 공헌이익 → **몇 건 팔려야 본전인지**를 먼저 계산한다
- 리뷰는 광고와 달리 **반감기가 길다**(검색에 계속 남는다) — 이걸 감안해 평가한다

### 자동화 범위 (REV-08)

| 자동 | 사람 |
|---|---|
| 모집 공고 문안 | 체험단 발주 승인 |
| 가이드라인 작성 | 대가 표시 문구 확인 |
| 발행 확인 체크리스트 | 최종 검수 |

**리뷰 본문에는 개입하지 않는다.** 문구를 지정해 주면 그건 후기가 아니라 광고 대본이고, 기만적 표시·광고 문제가 된다.

### 가이드라인에 반드시 넣을 것 (REV-09)

```
□ 대가 표시 문구를 본문 첫머리에 넣어주세요 (예시 제공)
□ 실제 사용 후 솔직하게 작성해주세요
□ 효능·효과를 단정하는 표현은 피해주세요 (업종 규제)
□ 타사 비방 금지
```

> 업종이 건강기능식품·의료·화장품이면 **표현 규제가 별도로 걸린다**. 가이드라인에 금지 표현 목록을 함께 준다.

## 4. 부정 리뷰 대응 (REV-10~11)

### 원칙 (REV-10)

| 하는 것 | 하지 않는 것 |
|---|---|
| 24시간 안에 답글 | 삭제 요청·법적 위협 |
| 사실 확인 후 사과·해결 제시 | 변명·책임 전가 |
| 오프라인 채널로 유도 | 공개 논쟁 |
| 개선했으면 그 사실을 알림 | 자작 5점으로 물타기 |

**답글은 그 리뷰어가 아니라 그걸 읽는 다음 구매자에게 쓰는 것이다.** 대응이 좋으면 부정 리뷰가 오히려 신뢰를 만든다.

### 조작은 하지 않는다 (REV-11)

- 자작 후기·지인 동원 → 기만적 표시·광고
- 리뷰 구매 → 같은 문제 + 플랫폼 제재
- **AI 생성 가상인물 후기** → 실존 인물처럼 보이는 AI 후기는 기만적 표시로 문제될 소지가 크다(관련 규제 동향은 [확인 필요])

## 5. 리뷰를 자산으로 (REV-12~13)

리뷰는 쌓아두는 게 아니라 **다시 쓰는 것**이다.

| 어디로 | 어떻게 |
|---|---|
| 상세페이지 | 자주 나온 표현을 그대로 인용 (동의 확인) |
| [[instagram]] 카드뉴스 | 후기 캡처 + 우리 답변 |
| [[blog]] | "이런 질문이 많았습니다" 형태로 |
| 광고 소재 | 실제 표현이 카피보다 먹힌다 |
| **[[messages]]** | ★고객이 쓴 표현 = 검증된 메시지 후보 |

**리뷰에서 반복되는 단어가 우리 메시지다.** 우리가 만든 카피보다 고객이 쓴 말이 잘 먹힌다. 이걸 [[messages]] 원장에 후보로 올린다.

### 재활용 시 (REV-13)

- 인용 전 **작성자 동의**를 받는다 (특히 이름·사진)
- 리뷰를 편집하지 않는다. 자르더라도 뜻이 바뀌면 안 된다
- **대가를 받은 후기를 재활용할 때도 표시가 따라간다**
