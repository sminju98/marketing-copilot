# video — 촬영 없이 만드는 제품 영상 (VID-01~12)

영상이 없는 이유는 대부분 하나다 — **찍을 사람도, 장비도, 시간도 없다.** 이 스킬은 그 전제를 지운다: **제품 화면(스크린샷·화면녹화)이 곧 촬영본**이고, 목소리는 AI가, 편집·자막은 자동화 도구가 한다. 소프트웨어·앱·웹서비스라면 실물 촬영보다 화면이 더 설득력 있다 — 고객이 사는 건 제품 화면 속 경험이다.

이 방식의 또 다른 장점은 **정책 안전성**이다. 유튜브가 2025년 7월 15일부터 '비진정성 콘텐츠'(템플릿 대량생산·같은 내레이션 슬라이드쇼 반복)를 수익화에서 배제했는데, **실제 자기 제품의 실제 화면**은 그 반대편에 있다 — 남의 소재 짜깁기가 아니라 1차 소재다.

## 실행 유형: [A] 장면 설계·대본·자막·썸네일 문구·업로드 카드 생성은 질문 없이 실행 / [P] AI 보이스 결제·게시는 config `approval_mode` / [H] 스크린샷·화면녹화 수집(제품 접근 권한이 사용자에게 있다), 공개 전환 버튼(유튜브 API 미심사 시). 유형별 차이는 [[role]].

## 0. 준비
```bash
cat "${MKT_COPILOT_HOME:-$HOME/.marketing-copilot}/context/"{brand,products,tone,claims}.md 2>/dev/null
marketing-copilot library list message --limit 10
marketing-copilot library list content --limit 20
```
- 어떤 메시지로 만들지 원장([[messages]])에서 먼저 고른다. 영상은 제작비가 가장 비싼 포맷이라 **검증 안 된 각도로 만들면 손실이 제일 크다.**

## 1. ★소재 수집 — 스크린샷을 "알차게" 딴다는 것 (VID-01~02)

### 어떤 화면을 따나 (VID-01)

아무 화면이나 이어붙이면 슬라이드쇼다. **문제→해결의 순간**을 딴다.

| 장면 | 무엇 | 왜 |
|---|---|---|
| ① 문제 화면 | 제품 쓰기 전의 고통 (지저분한 엑셀, 수동 작업) | 훅 — 시청자의 현재 |
| ② 진입 | 제품 첫 화면 | 전환의 시작 |
| ③ **핵심 동작** | 버튼 누르고 결과 나오는 **움직임** — 화면녹화 | 스크린샷보다 녹화. 변화가 설득한다 |
| ④ 결과 | Before/After, 완성된 산출물 | 돈이 되는 장면 |
| ⑤ 행동 유도 | 가격·시작 화면 | CTA 받침 |

**수집 가이드**: 실제 데이터가 보이면 고객 정보 마스킹, 해상도는 세로 영상 기준을 고려해 크게, 핵심 동작은 스크린샷 대신 **10~20초 화면녹화**(맥 `⌘⇧5`, 윈도우 `Win+G`).

### 사용자에게 요구하는 유일한 것 (VID-02)

위 5장면의 스크린샷·녹화 파일. **이것만 폴더에 넣으면 나머지는 전부 자동이다.** 부족한 장면은 AI가 목록으로 요구한다 — "③번이 없습니다. OO 기능 실행 장면 15초만 녹화해주세요."

## 2. 대본 — 자동 (VID-03~04)

### 구조 (VID-03)

```
0~3초    훅 — 문제 or 결과부터. "아직 이거 손으로 하세요?"
3~20초   장면 ②③ — 뭘 어떻게 하는지, 말은 짧게 화면이 말하게
20~40초  장면 ④ — 결과. 숫자는 claims.md 안의 것만
40~60초  CTA 1개 — "프로필 링크" 또는 검색어
```

- 쇼츠 60초·릴스·틱톡 겸용 세로(9:16) 기준. 롱폼 데모(2~3분)는 같은 구조를 늘린다
- **효능·수치는 `claims.md` 원장 안의 것만.** 원장 밖은 "확인 필요"로 사용자에게 되묻는다 — AI 보이스로 과장을 읽히면 그대로 표시광고법 문제다

### 장면-대본 매핑 (VID-04)

대본은 반드시 **장면 번호와 초 단위 매핑**으로 출력한다. 이게 있어야 편집 단계가 기계적이 된다.

```
[00:00-00:03 | 장면①] "견적서 아직 엑셀로 만드세요?"
[00:03-00:12 | 장면③] "버튼 하나면 끝납니다" (화면: 생성 과정 녹화)
...
```

## 3. 목소리 — AI 보이스 (VID-05)

| 도구 | 무료 | 유료 | 주의 |
|---|---|---|---|
| **타입캐스트** | 생성·재생 무제한, **다운로드 5분** | 프로 월 39,000원 | ★**무료분은 상업적 사용 불가**(출처 표기 조건) — 광고·마케팅 영상은 유료 플랜부터 |

- 톤 지시까지 대본에 포함한다(차분/활기, 문장별 쉼)
- 본인 목소리 녹음이 가능하면 그게 항상 낫다 — AI 보이스는 "없어서 못 만드는 것"을 없애는 도구지 상위호환이 아니다

## 4. 조립 — Vrew (VID-06)

| 기능 | 무료 한도 |
|---|---|
| 이미지·영상 + 음성 조립, 음성 인식 자막 자동 | 월 200크레딧 (1크레딧 = 음성분석 1분 또는 AI 음성 100자, 2026-04-22 통합 크레딧제) |

순서: 새 프로젝트 → 장면 파일을 대본 매핑 순서로 배치 → 보이스 업로드 → 자동 자막 → 자막 오타만 수정 → **세로 9:16 mp4** 내보내기.

**자막은 필수다** — 숏폼의 다수가 무음 시청이다. 자막 없으면 소리 끈 시청자를 전부 잃는다.

## 5. 썸네일·제목 — 자동 (VID-07)

- 제목 3안 + 설명란 + 태그를 대본에서 자동 생성
- 썸네일 문구는 제목과 다르게(같으면 정보량 손실). 이미지가 필요하면 [[imagefactory]] 발주

## 6. 업로드 (VID-08~09)

### 채널별 (VID-08)

| 채널 | 방식 | 근거 |
|---|---|---|
| 유튜브 쇼츠 | 스튜디오 **예약 업로드**(반자동) | 미심사 API 프로젝트 업로드는 '비공개 잠금'. 세로·3분 이하는 자동으로 쇼츠 분류(2024-10-15~) |
| 인스타 릴스 | 공식 API·Buffer로 **자동 게시** | Meta 공식 지원 |
| 틱톡 | 앱에서 수동 | 미심사 API는 '나만 보기' 강제 |

**같은 mp4 하나로 3채널 교차 게시**한다 — 워터마크 없는 원본으로.

### AI 합성 표시 (VID-09)

실제 사람·장소처럼 보이는 AI 합성 장면이 있으면 유튜브 '변경된 콘텐츠' 체크를 정직하게 표시한다. **제품 화면 + AI 내레이션은 통상 해당 없음** — 사람을 합성한 게 아니다. 애매하면 표시한다.
